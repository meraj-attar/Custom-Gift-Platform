1. Executive Overview & Core Objectives

CustomGift is an enterprise-grade personalized e-commerce application engineered to deliver handcrafted and customized gifts across India. Unlike generic retail platforms, CustomGift is tailored specifically to the nuances of gifting, where customers seek meaningful emotional keepsakes, anniversary frames, engraved keychains, customized mugs, and curated celebration hampers.

1.1 Purpose and Problem Statement

Traditional e-commerce platforms struggle with personalized gifting due to rigid product configurators, fragile web-based design canvas tools that crash on mobile devices, and impersonal checkout flows. CustomGift solves this by decoupling standard catalog purchasing from personalized consultation. Customers can seamlessly buy gifts through a frictionless Indian e-commerce checkout while collaborating directly with human artisans via WhatsApp for custom photo engraving, name stamping, and bespoke requirements.

1.2 Core Architectural Objectives

  • High Performance: Sub-50ms backend API responses powered by asynchronous FastAPI and efficient PostgreSQL indexing.
  • Strict Financial Integrity: Zero-trust server-side pricing, Razorpay payment verification using HMAC-SHA256 signatures, and atomic inventory management.
  • Real-World Indian Checkout Standards: Multi-step checkout with canonical 36 Indian States/UTs, 6-digit PIN validation, and optional address persistence.
  • Decoupled Personalization: Direct WhatsApp integration (8485089678) eliminating obsolete canvas bugs and fragile file upload gates.
  • Comprehensive Back-Office Operations: Complete administrative control over catalog, stock alerts, orders, payment audits, and customer support triage.
  • Military-Grade Defense: Sliding-window rate limiting, anti-tampering verification, timing-safe credential comparisons, and strict role-based access control.

4. Frontend Client Architecture (React 18 & Vite)

The frontend is architected as a modern Single-Page Application (SPA) using React 18, bundled with Vite for maximum developer productivity and optimized static production assets.

4.1 Component & Page Organization

  • src/pages/: Contains full-page route components: Home, Shop, ProductDetails, Cart, Checkout, Profile, About, Contact, Login, Register, ForgotPassword, ResetPassword, OrderDetails, and AdminDashboard.
  • src/components/: Reusable design system primitives: Navbar, Footer, ProductCard, WhatsAppIcon, PasswordStrengthMeter, SignOutConfirmationModal, and search controls.
  • src/context/: React Context providers: AuthContext (session, login, register, logout, token management) and CartContext (gift bag state, buy-now bypass, quantity adjustment).
  • src/services/api.js: Centralized Axios instance preconfigured with baseURL, default JSON headers, and dynamic Authorization Bearer token attachment.
  • src/utils/: Helper libraries: indianStates.js (canonical 36 States/UTs), validators.js (strict regex engines), and whatsapp.js (dynamic link generators).
UI Refinement Specification
Profile Page Navigation Architecture: As per the latest UI refinement, the redundant 'My Profile' text links were removed from the header navigation bar and footer. Profile access is now strictly provided via the interactive User Profile Icon in the header, which includes accessible aria labels, hover states, and seamless routing to '/profile'.

5. Backend Server Architecture (FastAPI & Services)

The CustomGift backend is built on FastAPI, leveraging Python 3.11 asynchronous capabilities, Pydantic type validation, and SQLAlchemy ORM.

5.1 Middleware Pipeline & Execution Order

  • 1. RequestIdMiddleware: Generates or propagates a unique UUID4 'X-Request-ID' header, appending it to request context and backend logs for end-to-end traceability.
  • 2. SecurityHeadersMiddleware: Injects enterprise security headers: X-Content-Type-Options: nosniff, X-Frame-Options: DENY, X-XSS-Protection: 1; mode=block, and Strict-Transport-Security.
  • 3. RateLimitMiddleware: An in-memory sliding-window limiter protecting sensitive routes (e.g. /api/auth/login, /api/auth/register, /api/contact) against brute-force and DDoS attacks.
  • 4. CORSMiddleware: Restricts cross-origin resource sharing strictly to configured frontend origins (e.g. http://localhost:5173, http://127.0.0.1:5173).

11. Security Architecture & Threat Protection Mechanisms

  • Password Encryption: Passwords are hashed using Passlib with Bcrypt and PBKDF2 with automatic unique salting.
  • Stateless JWT Authentication: HS256 signed JSON Web Tokens containing user identity, role, and expiration timestamp.
  • Dual-Track Recovery: 6-digit email OTPs (10-minute expiry) and 16-character emergency recovery codes (SHA-256 hashed).
  • Sliding-Window Rate Limiting: IP-based request throttling protecting authentication and contact submission routes.
  • Cryptographic HMAC Verification: Server-side HMAC-SHA256 signature verification for all Razorpay online payments.
  • Timing-Safe Comparisons: Utilizes constant-time comparison (hmac.compare_digest) to prevent side-channel timing attacks.

12. DevOps, Environment Configuration & Deployment Topology

  • Vite Production Build: Compiles React components into minified, hash-versioned static chunks for zero runtime compilation overhead.
  • FastAPI Uvicorn Runner: Multi-worker ASGI execution with automated restart capability and comprehensive structured logging.
  • Database Pooling: Connection pooling via SQLAlchemy with automatic reconnection and transaction rollbacks on failure.
